# win32cr

[![CI](https://github.com/mjblack/win32cr/actions/workflows/crystal.yml/badge.svg)](https://github.com/mjblack/win32cr/actions/workflows/crystal.yml) [![Crystal Latest CI](https://github.com/mjblack/win32cr/actions/workflows/crystal_latest.yml/badge.svg)](https://github.com/mjblack/win32cr/actions/workflows/crystal_latest.yml)

Win32 library bindings generated by [mjblack/winmd](https://github.com/mjblack/winmd) directly from
Microsoft's `Windows.Win32.winmd` metadata (the [win32metadata](https://github.com/microsoft/win32metadata)
NuGet package). The metadata version is pinned by the winmd shard (`lib/winmd/winmd.version`).

## Installation

Add this to your application's `shard.yml`:

```yaml
dependencies:
  win32cr:
    github: mjblack/win32cr
```

The generated bindings are committed, so nothing needs to be built to use the
shard.

To regenerate them (for example after updating the `winmd` dependency), run
`build.ps1` from the shard directory. It builds `winmd.exe` from `lib/winmd`,
fetches the pinned `Windows.Win32.winmd` into `winmd/`, and regenerates
`src/win32cr` with the override files in this directory:

```
C:\Projects\SomeCrystalApp\lib\win32cr> & .\build.ps1
```

Set `WINMD_CACHE=1` to reuse an already fetched metadata file.

## Usage

For more examples, please see the [examples](https://github.com/mjblack/win32cr/tree/master/examples) directory.

```crystal
require "win32cr"
require "win32cr/ui/windows_and_messaging"

alias WM = Win32cr::UI::WindowsAndMessaging # Simplifies code
WM.messageBoxW(Pointer(Void).null, pwstr("Message Box Body"), pwstr("Title"), WM::MESSAGEBOX_STYLE::MB_OK)
```
